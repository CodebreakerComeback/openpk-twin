# OpenPK-Twin

### Open-source pharmacokinetic modelling and virtual patient simulation toolkit

OpenPK-Twin is an open-source Python project focused on reproducible pharmacokinetic modelling, dose simulation, and virtual-patient analysis.

The goal is to make foundational pharmacokinetic simulation accessible to pharmacy students, researchers, and developers through transparent, reusable, and well-documented computational tools.

## Why OpenPK-Twin?

Pharmacokinetic modelling is essential for understanding drug disposition and supporting model-informed drug development. However, learning and experimenting with these models can require specialised software and programming knowledge.

OpenPK-Twin aims to provide an accessible Python-based environment for exploring pharmacokinetic principles.

## Planned features

- One-compartment pharmacokinetic models
- Two-compartment pharmacokinetic models
- Plasma concentration-time simulations
- Dose and dosing-interval exploration
- Virtual patient population simulations
- Monte Carlo-based variability analysis
- Model visualisation and reproducible examples
- Automated testing and scientific documentation

Features will be implemented incrementally and documented as they become available.

## Technology

- Python
- NumPy
- SciPy
- Matplotlib
- FastAPI (planned)

## Project status

**Early development.**

This project is being developed as an educational and research-oriented computational toolkit. Planned features are not yet necessarily implemented or experimentally validated.

## Intended users

- Pharmacy and Pharmaceutics students
- Pharmacokinetic researchers
- Pharmacometrics learners
- Pharmaceutical scientists
- Open-source healthcare technology developers

## Scientific and clinical disclaimer

OpenPK-Twin is intended for educational and research purposes. It is not a validated medical device and must not be used to make clinical dosing decisions or replace professional medical judgement.
